# ReStore

Telegram Mini App для заказов на установку приложений на iPhone. Интерфейс и админка используют Next.js, React и TypeScript. API, обработка платежей и Telegram-бот работают на Python и FastAPI. Каталог, заказы, бонусы и очередь сообщений хранятся в SQLite.

## Локальный запуск

Нужны Python 3.11+ и Node.js 20.9+. В PowerShell из корня проекта установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm.cmd install
```

В первом терминале запустите API:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале запустите Next.js:

```powershell
npm.cmd run dev
```

По адресу `http://127.0.0.1:3000` в обычном браузере отображается экран входа. Для проверки каталога и админки подключите бота и откройте Mini App из Telegram. FastAPI проверяет подписанные данные запуска для каталога, иконок, заказов и админки. При пустом `BOT_TOKEN` авторизоваться нельзя.

## Развёртывание на Ubuntu 26.04 LTS

Скопируйте проект целиком на VPS с публичным IPv4 и доступными входящими портами TCP 80 и 443. Из каталога проекта запустите:

```bash
sudo bash deploy.sh
```

Установщик предложит имя вида `restore-….duckdns.org`. Добавьте имя в аккаунте DuckDNS и вернитесь в терминал. Для уже добавленного имени используйте `sudo bash deploy.sh --domain restore-example`. Установщик попросит токены DuckDNS и бота, числовые Telegram ID администраторов и email для Let’s Encrypt. Менеджера, оферту и 2328.io можно заполнить при установке или позднее. [Личный кабинет DuckDNS](https://www.duckdns.org/)

Скрипт соберёт Next.js и окружение FastAPI, настроит Nginx, сертификат и его продление. Службы ReStore запускаются автоматически при загрузке сервера. DuckDNS обновляет адрес каждые пять минут. После успешной проверки HTTPS скрипт покажет ссылки на Mini App и бота.

Повторный `sudo bash deploy.sh` разворачивает новую сборку с сохранённым доменом, конфигурацией и SQLite. На время переключения сайт отвечает HTTP 503. Установщик сохраняет копию SQLite в `/var/lib/restore/backups/pre-deploy.sqlite` и проверяет сайт, API и доступ бота к Telegram через `getUpdates`. При сбое проверки установщик восстанавливает прежний релиз и базу. Параметры бота и оплаты хранятся в `/etc/restore/backend.env`, база по умолчанию — в `/var/lib/restore/restore.sqlite`.

```bash
sudo journalctl -u restore-api -u restore-web -f
sudo journalctl -u restore-duckdns -n 30
```

## Подключение Telegram

Скопируйте `.env.example` в `.env` и заполните поля. Перезапустите API после изменений.

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен BotFather. Бэкенд получает имя бота через getMe для реферальных ссылок. |
| `PUBLIC_URL` | Публичный HTTPS-адрес Mini App. Установщик подставляет его из домена. При ручном запуске пустое значение можно получить из стандартной кнопки Mini App в меню бота. Адрес должен вести на ReStore с доступным `/api/*`. |
| `ADMIN_IDS` | Числовые Telegram ID администраторов через запятую. |
| `ADMIN_CHAT_IDS` | Необязательная настройка для отдельного чата или списка получателей уведомлений. По умолчанию сообщения идут администраторам из `ADMIN_IDS`. Для личных чатов получатели должны сначала открыть бота. Для группы добавьте в неё бота и разрешите отправку сообщений. |
| `MANAGER_USERNAME` | Имя менеджера в Telegram для поддержки и установки. |
| `OFFER_URL` | HTTPS-ссылка на опубликованные условия покупки. Адрес сохраняется в заказе. При пустом значении витрина работает без оформления заказов. |
| `REFERRAL_PERCENT` | Начальный процент бонусов. Сохранённая в админке ставка применяется при создании новых заказов. |
| `RESTORE_API_URL` | Адрес FastAPI для Next.js. По умолчанию `http://127.0.0.1:8000`. При публикации задайте его до сборки Next.js. |

Запустите один экземпляр FastAPI, поскольку бот получает обновления через `getUpdates`. Если к этому токену раньше был привязан webhook Telegram, удалите его перед запуском. В живом боте `/start` показывает приветствие и кнопку открытия Mini App, `/admin` открывает админку для разрешённых пользователей, `/paysupport` направляет в поддержку. Первые приложения добавляются через админку.

Для продакшена выполните `npm run build` и `npm start`. Настройте HTTPS на публичном адресе и оставьте FastAPI доступным для Next.js. Храните `DATABASE_PATH` на постоянном диске.

## Оплата и установка

- Каталог, заказы и реферальные бонусы учитываются в рублях. Заполните `PAY2328_PROJECT` и `PAY2328_API_KEY`, чтобы включить 2328.io со счетами в рублях и выбором криптовалюты на странице провайдера. Провайдер отправляет подписанные уведомления на `${PUBLIC_URL}/api/webhooks/2328`. Применяйте этот режим для сценариев, в которых Telegram допускает стороннюю оплату. Для цифровых товаров и услуг внутри Telegram правила требуют Stars. [Правила Telegram](https://core.telegram.org/bots/payments-stars) · [Документация 2328.io](https://2328.io/api/payments)
- СБП отключена. Бонусами можно покрыть полную стоимость установки при достаточном балансе. Бонусы начисляются за подтверждённые платежи приглашённых пользователей. Ставка фиксируется при создании заказа, повторные подтверждения начисление не дублируют.
- После подтверждения бот отправляет покупателю и администратору номер заказа. В кнопке покупателя заполнен черновик сообщения для менеджера. Менеджер выполняет установку, а администратор отмечает её завершение в админке.

```powershell
npm.cmd run check
npm.cmd run build
```
